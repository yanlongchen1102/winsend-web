Setup Guide

WinSend Installation and Pairing Setup

Windows installation, iPhone installation, permission instructions and auto-pairing organized in one page for unified reference by other tutorials.

What This Page Covers

  • Windows client installation
  • iPhone installation and permission preparation
  • Auto-pairing instructions on same Wi-Fi
  • Checklist when encountering issues

1. Install Windows Client

  1. Download WinSend for Windows
  2. Prefer Microsoft Store, then launch WinSend. For an alternative installer, verify the source and publisher before running it.
  3. Confirm local network environment is available and keep app running

2. Install iPhone App

  1. Download WinSend from App Store
  2. Allow necessary permissions as prompted
  3. Prepare shortcuts or send entry for later use

3. Complete Auto-Pairing

Put both devices on a reachable private LAN; your PC may use Ethernet on that LAN. Allow Local Network access on iPhone and Windows Firewall access on the private network, then select the discovered PC.

If discovery fails, check running apps, permissions and firewall rules. Try manual IP entry only when the devices can reach each other; guest-network isolation may require switching to a trusted private network.

4. Checklist

  • WinSend on Windows is installed and running
  • WinSend on iPhone is installed
  • Both devices are on the same reachable private LAN
  • Necessary permissions are granted
  • Related shortcuts are configured if needed

Transfer modes and feature access

Local manual clipboard and file transfers are free. Automatic clipboard sync requires Pro; Shortcuts and cloud transfers have trial/Pro access. See the app for current offers. Files and photos require a reachable local network. Cloud Sync needs internet and supports clipboard text only. Automatic sync does not bypass iOS background or clipboard restrictions. Shortcuts require iOS 16+ and must be triggered. WinSend is an AirDrop-style alternative, not Apple AirDrop. WinSend does not deliberately compress transferred files; source apps or system export may change their representation, and device/network/storage limits still apply.

Frequently asked questions

Does WinSend need both devices on the same network?

Local files require a reachable LAN; the PC may use Ethernet on that LAN. Optional Cloud Sync relays client-encrypted clipboard text across networks with internet access, but not files or images.

Is WinSend free?

Local manual clipboard and file transfers are free. Automatic clipboard sync requires Pro; Shortcuts and cloud transfers have trial/Pro access. See the app for current offers.
