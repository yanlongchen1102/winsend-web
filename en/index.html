Questions, answered.

Is WinSend safe?＋

Yes. Local transfers go directly between your devices over your local network, without a cloud upload or account.

Does WinSend require internet?＋

Local file and clipboard transfers only require both devices to be on the same Wi-Fi network. Optional Cloud Sync supports encrypted clipboard relay across networks.

What can I transfer?＋

Photos, videos, files, and clipboard text. Photos and videos keep their original quality; files stay unchanged.

Can I use WinSend on different networks?＋

Yes. Enable cloud clipboard sync to share copied text when both devices have internet access. Files and photos still require a local network connection.

Can cloud clipboard transfer files or photos?＋

Cloud transfer supports clipboard text. Files and photos still transfer over your local network.

Does cloud clipboard need setup?＋

Yes. Open Cloud Sync on Windows, then enter the pairing code in WinSend’s Cloud Sync screen on iPhone and follow the in-app instructions.
