Is WinSend safe?

WinSend keeps file transfers local and offers optional client-encrypted cloud clipboard. Local HTTP transfer is not end-to-end encrypted, so use a trusted private network. Here are the security limits, analytics and installation precautions.

Last updated: October 8, 2026

Your files never touch a server

Files and photos travel directly between your devices over a reachable LAN, without a cloud file upload. The checked local path uses HTTP, not end-to-end encryption. Use a trusted private network, and remember that manual IP entry cannot bypass client isolation or firewall blocks.

About the SmartScreen warning

Microsoft Defender SmartScreen may show "Windows protected your PC" for an unfamiliar download or publisher. A reputation warning is different from a malware finding, but neither should be treated as proof that a file is safe.

Prefer the official Microsoft Store installation link. Before running an alternative installer, verify the source and publisher. Signing does not guarantee that every SmartScreen warning disappears; do not disable protection or bypass a malware warning.

Optional Cloud Sync is end-to-end encrypted

Cloud Sync relays clipboard text only. Clients encrypt messages with AES-256-GCM using keys derived from the sync code. Keep that code private: someone with it can derive the same keys. Content encryption does not hide connection metadata such as device names/identifiers, group information or IP addresses. This is not an independently audited security guarantee or a promise that servers retain no metadata.

What data the app collects

  • Transfer content and full file names are not intended analytics payloads. Local diagnostic logs may contain file names or clipboard previews; inspect them before sharing.
  • No account or personal information is required.
  • Pseudonymous usage analytics can associate feature/transfer events over time. Apple and RevenueCat handle purchases and entitlement checks. See the privacy policy for identifiers, metadata and local-log precautions.

Frequently asked questions

Is WinSend safe to use?

Local file transfers do not upload files to a cloud server. The checked local path uses HTTP, not end-to-end encryption, so use a trusted private LAN. Optional cloud clipboard encrypts text on the clients; usage analytics are separate.

Why does Windows show "Windows protected your PC" when I install WinSend?

SmartScreen can warn about an unfamiliar download or publisher. Use the official Microsoft Store link where possible. For an alternative installer, verify its source and publisher; a reputation warning is not proof of safety, and malware warnings must not be ignored.

Does WinSend upload my files to the cloud?

Files and photos use the local network. Optional Cloud Sync relays clipboard text encrypted on the clients with AES-256-GCM; it does not relay files or images. Keep the sync code private. Cloud connection metadata is not hidden by content encryption.

Who can see my transfers?

Local discovery uses mDNS, and the checked local transfer path uses HTTP rather than end-to-end encryption. Use a trusted private LAN; discovery and connection are not a guarantee of strong device authentication. Cloud sync requires the sync code, which must be kept private.
