Is WinSend safe?

Yes. WinSend was designed so that your data stays between your own devices. Here is exactly how it handles security and privacy — including an honest explanation of the Windows SmartScreen warning.

Last updated: August 25, 2026

Your files never touch a server

Regular transfers travel directly from your iPhone to your PC over your local Wi-Fi using a peer-to-peer connection discovered via mDNS. There is no cloud upload step, no intermediate storage, and no account system that could leak your data.

About the SmartScreen warning

When you first run the Windows installer, Microsoft Defender SmartScreen may show "Windows protected your PC". This appears for apps that are new or not yet code-signed and haven't built download reputation — it is not a virus or malware detection.

To install: click More info → Run anyway. Code-signing certificates cost hundreds of dollars per year; as the app grows, signed installers will replace this warning entirely.

Optional Cloud Sync is end-to-end encrypted

Cloud Sync relays clipboard text only, across networks. Messages are encrypted with AES-256-GCM using keys derived from your 6-digit sync code before they ever leave your device. The relay server only forwards ciphertext — it cannot read your content, and nothing is stored. You can also self-host the relay.

What data the app collects

  • No file names, file contents, or clipboard contents are ever collected.
  • No account or personal information is required.
  • Anonymous usage analytics (e.g. "a transfer completed") help improve reliability and contain no user content.
