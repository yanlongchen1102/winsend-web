How It Works

How WinSend Works

WinSend discovers nearby devices using mDNS and transfers files over your local network. Optional Cloud Sync shares clipboard text across networks; it does not transfer files or photos.

Core Features

After setup, run a WinSend Shortcut to send or fetch clipboard content without first opening the main app. Shortcuts require iOS 16 or later and are included in the free trial and in WinSend Pro. They do not provide continuous background clipboard monitoring.

  • ✓ Local file transfer without a cloud upload; optional cloud clipboard for text
  • ✓ mDNS discovery with a manual IP fallback when devices are reachable
  • ✓ Configured Shortcuts can be triggered with Back Tap

Technical Principle

On a reachable local network, mDNS (Multicast DNS) discovers your PC. Local transfers use HTTP/WebSocket connections, rather than end-to-end encryption, so use a trusted private network. A wired PC and a Wi-Fi iPhone can work on the same LAN. If discovery fails, manual IP entry can help, but cannot bypass firewall rules or client isolation.

The advantages of this approach are:

  • Data Security: Local files stay on the LAN; optional cloud clipboard encrypts text on the clients before relaying it
  • Transfer Speed: Local network transfer is much faster than cloud relay
  • Device Discovery: Automatic local discovery; manual IP fallback and optional cloud sync require separate setup

Implementation of Seamless Transfer

WinSend offers manually triggered Shortcuts for clipboard transfer. Automatic text sync is a separate Pro feature and remains subject to iOS execution and clipboard-access restrictions.

Specific implementation:

  1. Configure WinSend transfer script in Shortcuts app
  2. Bind shortcut to iPhone's "Back Tap" gesture
  3. After copying content in any app, tap back of phone to trigger transfer

You still need to trigger the Shortcut. With cloud sync configured, text can use the relay across networks or when the local text path fails. Images and files require the local path.

Use Cases

WinSend is particularly suitable for following use cases:

  • High-Frequency Small Content Transfer: Quick sync of daily content like text, links, verification codes
  • Cross-Device Workflow: Seamless work switching between iPhone and Windows
  • Temporary File Transfer: Photos, documents and other files temporarily needed to share
  • Privacy-Sensitive Content: Local file workflows on a trusted private LAN; leave cloud sync disabled when text must not use a relay
