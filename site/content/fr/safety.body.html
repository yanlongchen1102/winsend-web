Transfert local : choisissez un réseau de confiance

Sur le réseau local, fichiers et texte passent directement d’un appareil à l’autre, sans serveur intermédiaire. Ce transfert repose sur HTTP/WebSocket et n’est pas chiffré de bout en bout : une personne malveillante connectée au même réseau pourrait, en théorie, l’intercepter.

En pratique, utilisez WinSend chez vous ou sur un réseau dont vous connaissez les utilisateurs, et évitez les Wi-Fi publics (café, gare, hôtel). En déplacement, le partage de connexion de l’iPhone est une bonne solution. Pour des données professionnelles, suivez les règles de votre entreprise.

Transfert cloud : texte chiffré, métadonnées visibles

Le transfert cloud ne transmet que du texte. Celui-ci est chiffré sur vos appareils avec AES-256-GCM, à l’aide d’une clé dérivée de votre code de jumelage : le relais est conçu pour transporter le texte sans pouvoir le lire. En revanche, toute personne qui connaît ce code peut rejoindre votre groupe et lire les messages. Gardez-le pour vous.

Le chiffrement protège le contenu, pas les métadonnées : le relais voit les adresses IP, les noms et identifiants des appareils et des groupes, ainsi que les informations nécessaires pour rejoindre un groupe. Ce mécanisme n’a pas fait l’objet d’un audit de sécurité indépendant.

Bonnes pratiques

  • Téléchargez WinSend depuis le Microsoft Store ou l’App Store, via la page de téléchargement.
  • Si vous utilisez l’installateur .exe, vérifiez qu’il provient bien de winsend.app, et ne désactivez pas les protections de Windows.
  • Vérifiez le nom de l’appareil destinataire avant d’envoyer, et n’ouvrez pas un fichier reçu que vous n’attendiez pas.
  • Ne communiquez jamais votre code de jumelage, ni au support ni sur une capture d’écran publique.

Statistiques et journaux

WinSend collecte des statistiques d’utilisation pseudonymisées. Un identifiant permet de relier des événements dans le temps : il ne s’agit donc pas d’un anonymat complet. Les journaux de diagnostic restent sur l’appareil, mais peuvent contenir des noms de fichiers ou des extraits de texte : relisez-les avant de les envoyer.

Un doute ?

Interrompez le transfert et écrivez à support@winsend.app, sans joindre de contenu sensible ni votre code de jumelage. Si vous devez dépanner une connexion, suivez les conseils d’installation sans ouvrir votre réseau ou votre pare-feu plus que nécessaire.
