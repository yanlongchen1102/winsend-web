1. Installer les deux applications

Téléchargez WinSend sur Windows et sur l’iPhone. Ouvrez les deux applications. Laissez WinSend fonctionner sur le PC et gardez l’application iPhone au premier plan pour le premier test.

2. Vérifier le réseau

Les appareils doivent pouvoir communiquer sur le même réseau local. Un PC en Ethernet et un iPhone en Wi-Fi peuvent fonctionner ensemble : c’est l’accessibilité du réseau qui compte, pas le type de connexion.

Évitez un réseau Wi-Fi invité ou public. Certains routeurs isolent les appareils, même lorsqu’ils affichent le même nom de Wi-Fi. Un VPN ou des règles de routage peuvent aussi empêcher la connexion.

3. Autoriser seulement les accès nécessaires

  • iPhone : acceptez l’accès au réseau local. Si vous l’avez refusé, vérifiez l’autorisation de WinSend dans les réglages iOS.
  • Photos : donnez accès aux éléments que vous souhaitez sélectionner. Il n’est pas nécessaire de prétendre que toutes vos photos doivent être accessibles en permanence.
  • Windows : sur un réseau privé de confiance, vérifiez que le pare-feu permet les communications de WinSend. Ne désactivez pas le pare-feu pour tous les programmes.

4. Trouver l’appareil et tester l’envoi

Utilisez la découverte des appareils dans WinSend, puis sélectionnez le PC destinataire. Envoyez un petit document ou une photo. Vérifiez que le transfert est terminé et que le fichier reçu s’ouvre sur Windows.

Le PC n’apparaît pas : que vérifier ?

  1. WinSend fonctionne-t-il sur le PC et l’iPhone ?
  2. Les deux appareils sont-ils sur un réseau accessible, et non un Wi-Fi invité isolé ?
  3. L’accès au réseau local est-il autorisé sur iOS ?
  4. Le pare-feu autorise-t-il WinSend sur le profil réseau concerné ?
  5. Un VPN ou le routeur bloque-t-il la communication entre appareils ?

Si la découverte automatique échoue mais que les appareils sont accessibles, la connexion par adresse IP peut aider. Saisir une IP ne contourne ni l’isolation du routeur, ni un pare-feu, ni une route inaccessible.

Configurer le texte cloud plus tard

La synchronisation cloud exige Internet et la configuration du code de synchronisation sur les appareils. Elle ne permet pas d’envoyer un fichier hors du réseau local. Gardez ce code secret. Les Raccourcis doivent être déclenchés et ne rendent pas iOS capable d’exécuter WinSend en continu en arrière-plan.
