1. Installer WinSend sur le PC et l’iPhone

Téléchargez WinSend sur Windows (le Microsoft Store est recommandé) et sur l’iPhone depuis l’App Store. Ouvrez l’application sur le PC : elle se place dans la zone de notification et doit rester ouverte pour recevoir vos envois. Ouvrez ensuite WinSend sur l’iPhone.

2. Mettre les deux appareils sur le même réseau

L’iPhone et le PC doivent être sur le même réseau local : le même Wi-Fi à la maison, ou un PC branché en Ethernet sur la même box. Peu importe le type de connexion, l’essentiel est que les deux appareils puissent se joindre.

Les Wi-Fi invités, d’hôtel, d’université ou d’entreprise isolent souvent les appareils, même sous un nom de réseau identique. Dans ce cas, le plus simple est de connecter le PC au partage de connexion de l’iPhone.

3. Accorder les autorisations

  • Réseau local (iPhone) : acceptez la demande au premier lancement. Si vous l’avez refusée, réactivez-la dans Réglages > Confidentialité et sécurité > Réseau local > WinSend.
  • Photos (iPhone) : un accès limité aux photos que vous choisissez suffit. Inutile d’ouvrir toute votre photothèque.
  • Presse-papiers (iPhone) : pour éviter qu’iOS vous demande l’autorisation à chaque fois, réglez « Coller depuis d’autres apps » sur « Autoriser » dans Réglages > WinSend.
  • Pare-feu (Windows) : si Windows vous le demande, autorisez WinSend sur les réseaux privés. Inutile de désactiver le pare-feu.

4. Faire un premier essai

Sur l’iPhone, WinSend détecte le PC automatiquement. Sélectionnez-le, puis envoyez une photo. Si elle arrive sur le PC, dans le dossier Téléchargements (sous-dossier WinDrop par défaut), tout est prêt.

L’iPhone ne détecte pas le PC : que vérifier ?

  1. WinSend est-il ouvert sur le PC (icône dans la zone de notification) ?
  2. L’accès au réseau local est-il activé pour WinSend sur l’iPhone ?
  3. Les deux appareils sont-ils sur le même réseau, et pas sur un Wi-Fi invité ?
  4. Le pare-feu Windows autorise-t-il WinSend sur le profil réseau actuel ? Un réseau classé « Public » est souvent en cause.
  5. Un VPN est-il actif sur l’un des deux appareils ?

L’application iPhone propose aussi un diagnostic qui vérifie la connexion étape par étape. Si les deux appareils sont bien sur le même réseau mais que la détection automatique échoue, saisissez l’adresse IP du PC dans WinSend. Cela ne contourne pas un Wi-Fi qui isole les appareils : passez alors par le partage de connexion de l’iPhone.

Plus tard : copier du texte entre deux réseaux

Pour copier-coller du texte quand l’iPhone et le PC ne sont pas sur le même réseau, activez le transfert cloud (essai gratuit, puis Pro). La marche à suivre se trouve dans le guide du copier-coller. Les photos et les fichiers, eux, passent toujours par le réseau local.
