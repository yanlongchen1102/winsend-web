Avant de commencer

  • Installez et ouvrez WinSend sur l’iPhone et sur Windows.
  • Assurez-vous que les appareils peuvent communiquer sur le réseau local.
  • Autorisez le réseau local sur iOS et laissez l’application Windows fonctionner.
  • Vérifiez l’espace libre sur le PC pour les fichiers volumineux.

Besoin d’aide pour la première connexion ?

Envoyer depuis l’application Photos

  1. Dans Photos sur l’iPhone, sélectionnez la photo ou les vidéos à envoyer.
  2. Ouvrez le menu de partage d’iOS et choisissez WinSend. Si l’extension n’est pas visible, recherchez-la dans les options supplémentaires de partage.
  3. Dans WinSend, choisissez le PC destinataire et lancez l’envoi.
  4. Attendez la fin du transfert, puis vérifiez les fichiers reçus sur Windows.

Si le PC ne figure pas dans les destinations, ouvrez d’abord l’application WinSend sur l’iPhone pour vérifier la connexion. Faites un test avec une seule photo avant d’envoyer une grande sélection.

Envoyer un document depuis Fichiers

Dans Fichiers sur l’iPhone, ouvrez le partage du document et choisissez WinSend, puis le PC destinataire. Un élément qui n’est stocké que dans iCloud ou chez un autre fournisseur doit d’abord être disponible pour l’application source ; sa récupération peut nécessiter Internet.

Vous pouvez également sélectionner les fichiers depuis WinSend. Les possibilités d’export dépendent de l’application qui contient le document.

La qualité des photos est-elle conservée ?

WinSend ne compresse pas volontairement le fichier qu’il transfère. Toutefois, Photos, une autre application source ou l’export d’iOS peut fournir une représentation différente de l’original. Ne supposez pas qu’un transfert garantit tous les formats, métadonnées ou éléments d’une Live Photo.

Pour un usage où le format original est important, vérifiez le type et la taille du fichier reçu, ainsi que son ouverture dans votre logiciel Windows. Des codecs supplémentaires peuvent être nécessaires pour certains formats.

Pourquoi le transfert échoue-t-il ?

Les causes fréquentes sont une destination non accessible, une permission réseau refusée, un pare-feu, une interruption de l’application ou un manque d’espace. Réessayez avec un fichier plus petit et suivez le diagnostic de connexion. Ni une adresse IP saisie manuellement ni l’option cloud ne contournent ces obstacles pour envoyer des fichiers.

Et si les appareils sont sur des réseaux différents ?

WinSend ne propose pas de relais cloud pour les fichiers, photos ou vidéos. Pour ce parcours, rapprochez les appareils sur un réseau local accessible ou choisissez une autre méthode adaptée, par exemple un câble ou un service de stockage dont vous acceptez les conditions.
