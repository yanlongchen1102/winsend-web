Guide · Presse-papiers et Raccourcis

Copier sur l’iPhone, coller sur Windows

Partagez un lien, une liste ou un paragraphe. Commencez par un envoi manuel local, puis configurez un Raccourci si ce parcours vous convient.

Préparer la connexion

Installez WinSend sur Windows et sur l’iPhone, ouvrez les applications et vérifiez qu’elles peuvent communiquer sur le réseau local. L’application Windows doit rester en fonctionnement. Suivez le guide d’installation si le PC n’apparaît pas.

Partager du texte manuellement

Copiez le texte sur l’iPhone, puis utilisez la fonction de partage du presse-papiers dans WinSend vers le PC connecté. Vérifiez sa réception et collez-le sur Windows avec Ctrl+V. Dans l’autre sens, copiez sur Windows et récupérez le texte dans WinSend sur l’iPhone avant de le coller.

Le partage manuel local est gratuit. L’accès au presse-papiers reste soumis aux autorisations et aux restrictions d’iOS ; cela ne crée pas une surveillance permanente des autres applications.

Configurer un Raccourci WinSend

  1. Sur iOS 16 ou ultérieur, ouvrez l’application Raccourcis et ajoutez l’action WinSend adaptée à l’envoi de texte vers le PC.
  2. Vérifiez les paramètres de l’action et la connexion avec Windows. Les droits d’essai/Pro affichés dans WinSend s’appliquent.
  3. Copiez un texte, puis déclenchez le Raccourci. Vous pouvez l’associer à Toucher le dos dans les réglages d’accessibilité d’iOS selon votre appareil.
  4. Attendez la réception sur Windows et collez avec Ctrl+V. En cas d’échec, testez d’abord la connexion dans l’application principale.

Le Raccourci doit être déclenché. Il ne contourne ni un réseau inaccessible ni les limites d’exécution en arrière-plan d’iOS. Aucun quota précis ni tarif n’est garanti par cette page.

La synchronisation automatique est-elle possible ?

La synchronisation automatique du texte est une fonctionnalité Pro, lorsque iOS permet à WinSend de s’exécuter et d’accéder au presse-papiers. Elle ne garantit pas une synchronisation permanente lorsque l’application est en arrière-plan ou suspendue. Pour un envoi volontaire depuis une autre application, utilisez un Raccourci configuré et déclenché.

Partager du texte sur différents réseaux

La synchronisation cloud facultative peut partager du texte lorsque les appareils ont Internet et que le code de synchronisation est configuré. Un accès d’essai/Pro s’applique. Si le cloud est configuré et disponible, un envoi de texte peut aussi l’utiliser lorsque le parcours local échoue.

Le cloud ne transmet ni fichiers ni images du presse-papiers. Le texte est chiffré sur les appareils, mais les métadonnées de connexion restent distinctes. Gardez le code secret et consultez les limites de sécurité.
