Copier-coller entre iPhone et PC Windows

Un lien, une adresse, un paragraphe : copiez-le d’un côté, collez-le de l’autre. Commencez par l’envoi manuel, gratuit, puis gagnez du temps avec un Raccourci.

Avant de commencer

WinSend doit être installé sur les deux appareils et ouvert sur le PC, et l’iPhone et le PC doivent être sur le même réseau local. Si le PC n’apparaît pas, suivez le guide d’installation.

De l’iPhone vers le PC

Copiez le texte sur l’iPhone, ouvrez WinSend et touchez « Envoyer au PC ». Le texte arrive dans le presse-papiers Windows : collez-le avec Ctrl+V.

Du PC vers l’iPhone

Copiez le texte sur le PC (Ctrl+C), puis touchez « Recevoir du PC » dans WinSend sur l’iPhone. Le texte est copié sur l’iPhone, prêt à être collé. Cela fonctionne aussi avec une image copiée sur le PC : elle est enregistrée dans Photos.

Ce copier-coller manuel est gratuit et sans limite. En mode manuel, WinSend ne lit le presse-papiers que lorsque vous touchez l’un de ces boutons.

Plus rapide : le Raccourci Toucher le dos

  1. Dans WinSend sur l’iPhone, touchez « Configurer les raccourcis », puis « Ajouter » pour importer le raccourci « WinSend Copy Sync » (iOS 16 ou version ultérieure).
  2. Ouvrez Réglages > Accessibilité > Toucher > Toucher le dos de l’appareil.
  3. Choisissez « Toucher deux fois », puis sélectionnez « WinSend Copy Sync ».
  4. Copiez un texte, touchez deux fois le dos de l’iPhone, puis faites Ctrl+V sur le PC.

Le Raccourci fonctionne sans ouvrir WinSend, et vous pouvez aussi le lancer avec Siri ou depuis l’écran d’accueil. S’il ne répond plus, ajoutez-le à nouveau depuis WinSend. Les Raccourcis s’essaient gratuitement, puis nécessitent WinSend Pro.

Synchronisation automatique (Pro)

Avec WinSend Pro, le texte copié peut se synchroniser automatiquement entre l’iPhone et le PC. iOS limite toutefois ce que les applications peuvent faire en arrière-plan : la synchronisation fonctionne quand WinSend est ouvert, mais pas forcément lorsqu’il est en arrière-plan ou que l’iPhone est verrouillé. Pour envoyer un texte depuis n’importe quelle application, le Raccourci reste la solution la plus fiable.

Pas sur le même réseau : le transfert cloud

PC au bureau, iPhone en 4G ? Activez le transfert cloud. Sur le PC, cliquez sur l’icône WinSend dans la zone de notification, puis sur « Cloud Transfer » > « Generate Pairing Code & Connect » (l’application Windows est en anglais). Sur l’iPhone, ouvrez « Transfert cloud » et saisissez le code de jumelage à 6 chiffres.

Le cloud ne transmet que du texte, chiffré sur vos appareils, et pas les fichiers ni les images. Une fois configuré, il prend aussi le relais si l’envoi local échoue. Il s’essaie gratuitement, puis nécessite WinSend Pro. Ne communiquez votre code de jumelage à personne ; le détail est sur la page sécurité.
