本教程将指导你完成 WinSend 的完整安装和配对流程，包括 Windows 端和 iPhone 端的安装、权限设置以及设备间的自动配对。

完成本教程后，你的 iPhone 和 Windows 设备就可以在同一网络下互相发现并传输文件了。

详细设置教程

按照以下步骤完成安装和配对

第一步：安装 Windows 客户端

先在 Windows 电脑上安装 WinSend 客户端。

  1. 打开 Windows 下载页，优先使用 Microsoft Store
  2. 完成安装后双击启动应用
  3. 确认本地网络环境可用，并保持应用运行

第二步：安装 iPhone 端应用

在 iPhone 上从 App Store 下载 WinSend。

  1. 从 App Store 下载 WinSend
  2. 根据提示允许必要权限（本地网络等）

第三步：完成自动配对

确保两端处于可互通的专用局域网，电脑通过网线接入也可使用。允许 iPhone 本地网络权限和 Windows 防火墙访问后，选择发现的电脑。

如果发现失败，检查两端运行状态、权限与防火墙。设备可达时可尝试手动 IP；访客网络或 AP 隔离可能需要切换到可信专用网络，手动 IP 不能绕过隔离。

💡 提示

  • • 确保两台设备位于可互通的专用局域网
  • • Windows 端的 WinSend 需要保持运行状态
  • • 首次连接可能需要等待 10-30 秒

检查清单

完成安装后，请确认以下各项：

✓ Windows 端 WinSend 已安装并在运行
✓ iPhone 端 WinSend 已安装
✓ 两台设备在同一 Wi-Fi
✓ 必要权限已经允许
✓ 需要快捷指令时，相关入口已配置完成
