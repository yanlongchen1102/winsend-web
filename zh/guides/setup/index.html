Setup Guide

WinSend 安装与配对设置

把 Windows 安装、iPhone 安装、权限说明和自动配对都单独整理在一页，供其他教程统一引用。

这一页包含什么

  • Windows 客户端安装
  • iPhone 端安装和权限准备
  • 同一 Wi-Fi 下的自动配对说明
  • 遇到问题时的检查清单

1. 安装 Windows 客户端

  1. 下载 WinSend Windows 客户端
  2. 完成安装后首次启动应用
  3. 确认本地网络环境可用，并保持应用运行

2. 安装 iPhone 端应用

  1. 从 App Store 下载 WinSend
  2. 根据提示允许必要权限
  3. 准备后续快捷指令或发送入口

3. 完成自动配对

确保 iPhone 和 Windows 电脑处于同一 Wi-Fi。WinSend 会优先通过同一网络下的发现机制完成连接。

如果没有及时发现设备，优先检查应用是否运行、网络是否一致、权限是否允许。

4. 检查清单

  • Windows 端 WinSend 已安装并在运行
  • iPhone 端 WinSend 已安装
  • 两台设备在同一 Wi-Fi
  • 必要权限已经允许
  • 需要快捷指令时，相关入口已配置完成
