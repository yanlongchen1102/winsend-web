# iPhone 用快捷指令 + WinSend 实现一键剪贴板同步到Windows

# 

在日常使用中，很多人都会遇到这样的问题：

- iPhone 想把内容传到 Windows 电脑，很麻烦
- AirDrop 只能在苹果设备之间使用
- 需要打开各种 App，步骤繁琐
- 剪贴板无法直接同步

WinSend致力于打造iPhone与WinSend的生态。

通过 **WinSend + iPhone 快捷指令**，你可以做到：

> **无需打开任何传输 App，只需轻点两下 iPhone 背面，就能把剪贴板内容自动发送到 Windows。**
>

# ⚙️ 原理说明（简单理解）

整个流程其实非常简单：

- 使用 iPhone 的「快捷指令」读取剪贴板
- 通过网络发送到 Windows
- WinSend 在后台接收并处理

再结合 iPhone 的「轻点背面」功能，就实现了：

👉 **“全局任意位置触发 + 自动剪贴板同步”**

# 📥 教程：一步一步教你配置

下面是完整设置流程，大约 3 分钟即可完成。

---

## Step 1：在 Windows 上安装 WinSend 桌面版

1. 访问 WinSend官网 [winsend.app](http://winsend.app)  
2. 下载并安装 WinSend.exe
3. 打开软件并保持运行
4. 确保电脑和 iPhone 连接同一wifi

---

## Step 2：在iPhone上下载WinSend iOS版

1. 在App Store搜索WinSend下载安装
2. 允许必要权限（如网络访问、剪贴板）
3. 添加快捷指令

---

## Step 3：等待自动配对成功

WinSend会自动发现同一网络下的iPhone和Window，并自动进行配对连接。

---

## Step 4：开启「轻点背面」触发

在 iPhone 中打开：

> 设置 → 辅助功能 → 触控 → 轻点背面
> 

然后：

- 选择「轻点两下」或「轻点三下」
- 下滑，找到并绑定刚刚添加的快捷指令

---

## Step 5：测试效果

1. 在 iPhone 上复制一段文字。
2. 轻点两下手机背面。
3. 选择同步方向，从电脑复制/复制到电脑。
4. 立即传输成功。

如果你看到内容已经同步，说明配置成功 🎉
