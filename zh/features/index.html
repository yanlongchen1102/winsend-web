文件与剪贴板

怎么用。

从本地文件传输、双向剪贴板，到跨网络文字分享，看看 WinSend 怎么用。

文件传输 · Windows → iPhone

拖入、发送、完成。

把照片、视频或文件拖入 Windows 端 WinSend，通过本地 Wi-Fi 直接发送到 iPhone，随时保存或打开。

不上传云端保留原始画质支持大文件
Windows → iPhone

剪贴板 · Windows → iPhone

电脑复制，
iPhone 粘贴。

在 Windows 复制清单、链接或整段文字，在 WinSend 中获取，然后粘贴到 iPhone 的任意 App。

支持文本与链接无需重新输入跨 App 使用
Windows → iPhone

快捷指令 · iPhone → Windows

iPhone 发送，
电脑 Ctrl+V。

先设置 WinSend 快捷指令，再运行它，将 iPhone 上复制的文字发送到 Windows 剪贴板，无需打开 WinSend。

iOS 快捷指令支持轻点背面任意位置粘贴
设置剪贴板快捷指令 →
iPhone → Windows

云剪贴板

不在同一个 Wi-Fi，
文字也能接着用。

电脑连着办公室网络，iPhone 用着移动数据？启用云剪贴板后，复制的文字仍能在两台设备之间传递。

云端目前支持剪贴板文本；文件和照片仍通过局域网传输。

传输方式示意

  1. 1

    开启云同步

    在 Windows 端打开云同步，获取配对码。

  2. 2

    连接 iPhone

    在 WinSend 的云同步页面输入配对码，按应用内提示完成设置。

  3. 3

    跨网络分享文字

    保持两端联网，发送或获取剪贴板文本，再粘贴使用。
